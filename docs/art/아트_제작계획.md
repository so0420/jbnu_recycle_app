## 2. SVG 캐릭터 규칙
- 몸은 **실제로 버리는 물건 모양**. 한눈에 "페트병이다"가 보여야 한다.
- 진화할수록 **올바른 배출 상태**에 가까워진다 (라벨이 벗겨짐, 상자가 펼쳐짐, 캔이 깨끗해짐).
- 역할(로드)은 실루엣으로 구분: 탱커는 각지고 넓게, 딜러는 뾰족하게, 힐러는 둥글게.
- 모든 캐릭터는 같은 함수(`face`, `styler`)를 써서 눈·볼·선 굵기를 통일한다.
- 앱에서는 `frontend/src/art/` 에 캐릭터별 TS 함수로 넣고, `<Remon species="petring" stage={2} variant="shiny" />` 컴포넌트로 그린다.

## 3. 이미지 생성 AI를 쓸 때 "AI 같지 않게" 하는 방법
1. **실제 매체를 구체적으로 지정**한다. "귀여운 일러스트"가 아니라 "손으로 잉크를 칠한 굵기가 고르지 않은 외곽선, 납작한 색"이라고 쓴다.
2. **AI 특유의 표현을 금지어로** 넣는다: 그라데이션, 광택, 3D, 글로우, 블룸, 역광, 배경 흐림, 과한 디테일, 글자.
3. **우리 SVG 캐릭터를 참고 이미지로** 넣는다 (`--ref`). 모델이 캐릭터를 새로 지어내지 않게 한다.
4. **후처리**: 게임 팔레트 22색으로 다시 칠해서 그라데이션을 없애고, 살짝 줄였다 키워서 지나친 디테일을 뭉개고, 종이 질감을 넣는다. 후처리 결과가 앱의 SVG 캐릭터와 같은 색을 쓰게 된다.
5. **사람 검수 체크리스트** (`gen_image.py` 실행 끝에 출력): 손발 개수, 글자 낙서, 원본과 다른 캐릭터, 남은 광택, 과한 배경.
6. 글자는 이미지에 넣지 않는다. 제목·설명은 앱이나 발표 자료에서 텍스트로 얹는다.
7. 발표 자료에 "일러스트 일부는 이미지 생성 AI로 만든 뒤 팀이 수정함"이라고 출처를 적는다.

## 4. 순서
1. 팀이 그림체(A 스티커 / B 리소 / C 도트)를 고른다.
2. Claude가 일반 5종 × 3단계, 보스 3종, 정원 4단계, 아이콘을 SVG로 만든다 (3주차 화면 개발 전).
3. 리몬을 PNG로 뽑아 참고 이미지로 쓰고, 온보딩·배너 일러스트를 생성한다.
4. 희귀·에픽·전설, 나머지 보스 2종을 만든다 (4주차).

## 5. 비용
이미지 생성은 약 10장 × 시도 3~4번 = 30~40장 수준. 모델 가격은 생성 시점에 OpenAI 가격표로 확인하고, OpenAI 계정에 월 사용 상한을 걸어 둔다.
