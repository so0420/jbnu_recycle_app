# 리사이클 앱 게임 시스템 설계 v2

> v1 2026-11-16 (지역 대전 중심) → **v2 2026-11-16 (수집·성장·전투 중심)**
> `개발계획.md` 의 게임 부분 상세. 숫자는 모두 **초기값**이며 시범 운영 데이터로 다시 맞춘다.

### v1 → v2 무엇이 바뀌었나
| v1의 문제 | v2의 해결 |
|---|---|
| 할 일이 배출일 1~2분뿐 | **분리 가방**(집에서 스캔) + **탐사** + **동 레이드** → 배출 없는 날에도 1~3분 들를 이유 |
| 공격 버튼 하나, 고민이 없음 | **리몬(수집 캐릭터) 파티 + 상성 + 작전 설정** 으로 자동 전투 → 조합이 결과를 바꿈 |
| 내 행동 효과가 안 보임 (공격 1회 = 청결도 0.4) | 전투 피해량·레벨업·진화·도감 칸처럼 **개인 단위로 바로 보이는 보상** |
| 맞기만 하고 대응할 수 없음 | 공격 = 상대 동에 **오염 괴물 소환**. 상대 주민이 잡으면 오히려 전리품 |
| 캐릭터 선택지 없음 | 리몬 37종 수집, 육성 대상 선택, 진화, 별 강화 |
| 지역 경쟁만 있음 | 경쟁(괴물 보내기)은 한 요소로 축소. **협동(동 레이드)** 이 중심 |

## 1. 한 줄 소개와 원칙

> **"제대로 버린 쓰레기가 재료가 되고, 재료로 리사이클 몬스터 '리몬'을 모으고 키워서, 동네에 나타난 오염 괴물을 이웃과 함께 물리친다."**

| 원칙 | 기준 |
|---|---|
| 진행의 대부분은 **실제 분리배출**에서 | 주간 재료 획득량의 **70% 이상**이 배출 인증·가방 정산·주간 배출 미션에서 나오도록 수치를 맞춘다 (3-2) |
| **올바른 습관 = 강해지는 법** | 진화 조건이 "라벨 떼기, 헹구기, 상자 펴기" 같은 실제 습관이다 (5-3) |
| 짧게, 자주 | 배출 없는 날 1~3분, 배출일 3~5분. 스태미나 같은 대기 제한은 없다. 진행 속도는 실제 배출 횟수가 정한다 |
| 결제 없음 | 뽑기(캡슐)는 있지만 돈으로 살 수 없다. 천장(확정 보상) 있음 |
| 구현 가능 | 전투는 **서버가 계산해서 결과 기록만 보내고 프론트는 재생만** 한다. 게임 엔진 없이 카드형 UI로 만든다 |

## 3. 자원

### 3-1. 종류와 얻는 법

| 자원 | 쓰는 곳 | 주로 얻는 곳 |
|---|---|---|
| **재료 5종**: 플라스틱 칩 / 펄프 / 알루미늄 / 유리 조각 / 비닐 필름 | 같은 타입 리몬 레벨업·진화 | 가방 정산(품목 1개당 그 품목 타입 재료 5), 인증 사진 기본 8 |
| 특수 재료: 볼트 코어(전지) / 섬유 실(의류) | 에픽 리몬 육성 | 폐건전지 수거함·의류수거함에서 인증 |
| **정화의 결정** | 3단계 진화 | 동 레이드 보스 처치 |
| **에코 코인** | 레벨업 비용, 재료 교환 | 인증, 미션, 레이드, 탐사 |
| **리몬 캡슐** | 열면 리몬 1마리 | 배출 인증 1회당 1개, 주간 미션, 레이드 처치 |
| **도전권** | 레이드 도전, 괴물 보내기 | 인증 1회 +2, 배출일 첫 인증 +1, 하루 무료 1장. 보유 상한 10장 |

- **재료 교환**: 같은 단계 재료끼리 3:1 교환(예: 플라스틱 칩 3 → 유리 조각 1). 에코 코인 → 재료 5:1.
- 실제 가정 쓰레기는 플라스틱과 종이가 많고 유리와 캔은 적다. 그래서 **유리·금속 리몬은 키우기 어렵고 그만큼 귀하다.** 어디에 재료를 쓸지가 첫 번째 고민거리가 된다.

### 3-2. 일주일 수입 추정 (보통 사용자: 배출 주 3회, 회당 가방 품목 4개, 70%가 깨끗)

| 출처 | 재료 | 실제 배출과 연결 |
|---|---|---|
| 인증 3회 × (기본 8 + 가방 4개×5 + 깨끗 보너스 약 3) | 약 93 | ✅ |
| 주간 미션 "인증 3회" | 30 (원하는 타입) | ✅ |
| 동 레이드 (하루 약 2회 × 1) | 약 15 | |
| 탐사 (하루 약 1.5회 수령 × 2) | 약 21 | |
| **합계** | **약 159** | **약 77%** ✅ 목표 70% 이상 |

- 코인: 주 약 350 (인증 60, 일일 미션 210, 레이드 75 등)
- 캡슐: 주 약 5개 (인증 3, 주간 미션 1, 레이드 처치 약 1)

## 4. 분리 가방 (집 ↔ 수거장 연결)

1. 집에서 페트병을 재활용 통에 넣을 때 **찍는다** → AI가 배출 방법을 알려 주고 **가방에 품목 1개**가 담긴다.
2. 같은 사진에서 AI가 **"깨끗한가?"**(오염·라벨·이물질)도 함께 판정한다 → 깨끗하면 ✨ 표시.
3. 배출일에 수거장에서 인증하면 **가방 전체를 정산**한다: 품목마다 재료 5, ✨ 품목은 +1. 캡슐의 희귀 확률도 오른다. 정산 후 가방은 비워진다.
4. 인증 없이 스캔만 하면 재료는 0이다(계정 경험치 +5와 품목 도감만). → 핵심 보상은 계속 **실제 배출**에 묶여 있다.

| 항목 | 값 |
|---|---|
| 가방 용량 | 처음 6칸 → 정원 레벨과 업적으로 최대 15칸 |
| 같은 물건 반복 스캔 | 사진 pHash로 중복 판정 → 담기지 않음 |
| 가방에 담은 뒤 보관 기한 | 7일 (지나면 사라짐. 쌓아 두었다가 한 번에 정산하는 것 방지) |

> 한계: 가방에 담은 물건을 실제로 다 버렸는지는 확인할 수 없다. 용량 상한으로 최대 이득을 제한하고, 발표에서 한계로 밝힌다.

## 5. 리몬 (수집 캐릭터)

### 5-1. 타입과 역할

| 타입 | 재료 | 역할 | 대표 스킬 (3턴마다) |
|---|---|---|---|
| **금속** | 알루미늄 | 탱커: 체력·방어 높음 | **찌그러뜨리기**: 2턴 도발 + 받는 피해 −30% |
| **유리** | 유리 조각 | 딜러: 공격 높고 약함 | **파편 난사**: 적 전체에 공격력 80%, 치명 30% |
| **플라스틱** | 플라스틱 칩 | 힐러 | **재생**: 체력이 가장 낮은 아군 회복(공격력 150%) + 오염 제거 |
| **종이** | 펄프 | 서포터 | **겹겹이 포장**: 아군 전체에 보호막(공격력 100%) |
| **비닐** | 비닐 필름 | 방해 | **휘감기**: 적 1명 1턴 행동 불가(보스는 속도 −30%) |
| 전지 (에픽) | 볼트 코어 | 연쇄 딜러 | **방전**: 3회 연쇄 공격 |
| 섬유 (에픽) | 섬유 실 | 만능 | **덧대기**: 아군 전체 회복 + 방어 증가 |

**상성 (1.5배 / 0.75배)**: 금속 → 유리 → 비닐 → 종이 → 플라스틱 → 금속 (화살표 방향이 유리). 에픽 타입은 상성이 없다.

### 5-2. 도감 구성 (37칸)

| 구분 | 종 | 진화 | 칸 수 | 얻는 법 |
|---|---|---|---|---|
| 일반 | 타입당 1종 × 5 | 3단계 | 15 | 캡슐 (캡슐 타입 = 정산한 가방에서 가장 많은 품목 타입) |
| 희귀 | 타입당 1종 × 5 | 3단계 | 15 | 캡슐 25% 확률 |
| 에픽 | 전지·섬유 2종 | 3단계 | 6 | 해당 수거함에서 **처음 인증하면 확정**, 이후 특수 재료로 육성 |
| 전설 | 재생의 정령 "리버스" | 1단계 | 1 | **일반·희귀 10종 모두 수집** 시 해금 퀘스트 |
| (반짝이) | 모든 종 | – | 별도 표시 | 캡슐에서 2%, ✨ 비율이 높으면 4% |

일반 종 이름 예시(팀에서 수정): 페트링→페트롤→페트라곤 / 박스곰→큰박스곰→골판지킹 / 캔돌이→캔버스터→강철캔기사 / 유리새→크리스탈새→글라스피닉스 / 비닐리→비닐뱀→랩드래곤 / 볼트쥐→볼트여우→볼트라이온 / 솜뭉치→털실양→패브릭골렘

**캡슐 규칙**
- 희귀 25%. 희귀가 4번 연속 안 나오면 5번째는 **희귀 확정**(천장).
- 가방 정산의 ✨ 비율이 100%면 희귀 확률 +10%p (35%).
- **중복**: 같은 종이 또 나오면 **별 +1**(최대 5, 별마다 능력치 +5%). 별 5개 뒤로는 그 타입 재료 30으로 바꾼다. 중복도 버려지지 않는다.

### 5-3. 성장: 레벨·진화·별

| 단계 | 레벨 상한 | 진화 조건 (**실제 습관**) |
|---|---|---|
| 1단계 | Lv10 | – |
| → 2단계 | Lv20 | Lv10 + 재료 20 + **습관 퀘스트 5회** |
| → 3단계 | Lv30 | Lv20 + 재료 50 + **습관 퀘스트 15회** + 정화의 결정 1 |

**습관 퀘스트** (스캔 사진을 AI가 판정, 해당 타입 품목만 카운트)

| 타입 | 습관 | AI 판정 질문 (`guides.yaml` 의 `habits`) |
|---|---|---|
| 플라스틱 | 라벨 떼고 헹군 투명 페트 | "Is the label removed and the bottle clean?" |
| 종이 | 테이프·송장 떼고 펼친 상자 | "Is the box flattened with tape removed?" |
| 금속 | 헹구고 이물질 없는 캔 | "Is the can empty and free of foreign objects?" |
| 유리 | 뚜껑 분리한 빈 유리병 | "Is the cap removed and the bottle empty?" |
| 비닐 | 음식물 안 묻은 비닐 | "Is the plastic film clean?" |

→ **"이 리몬을 진화시키려면 페트병 라벨을 떼야 한다"**: 게임 목표와 교육 목표를 한 문장으로 연결하는 핵심 장치다.
→ 판정 기준은 0.6으로 느슨하게 잡는다(AI가 틀려서 억울한 경우를 줄이기 위해).

**능력치 공식**
```
능력치 = 종 기본값 × (1 + 0.06 × (레벨−1)) × 단계 배율(1 / 1.5 / 2.2)
                  × 희귀도(일반 1.0, 희귀 1.1, 에픽 1.25, 전설 1.45) × (1 + 0.05 × 별)
레벨업 비용 (Lv → Lv+1) = 해당 타입 재료 (3 + Lv) + 코인 5 × Lv
```
| 구간 | 재료 누적 | 보통 사용자가 **한 마리에 집중**할 때 (플라스틱 기준) |
|---|---|---|
| Lv1 → 10 | 72 | 약 1주 |
| Lv10 → 20 | 175 | +2.5주 |
| Lv20 → 30 | 275 | +4주 |

파티 3마리를 고르게 키우면 약 3배 느리다 → 파티 전원 Lv20까지 **약 2~3개월**. 장기 목표가 된다.
유리·금속은 재료가 귀해서 더 오래 걸린다 → 재료 교환·탐사로 보충할지 고민하게 된다.

### 5-4. 정원 (계정 레벨)
v1의 캐릭터(씨앗→새싹→나무→숲)는 **계정 레벨을 보여 주는 홈 화면 정원**으로 쓴다. 공식은 v1과 같다(다음 레벨 필요 경험치 = 40 + 20 × Lv).

| 정원 레벨 | 해금 | 보통 사용자 도달 |
|---|---|---|
| 1 | 스캔, 인증, 분리 가방, 스타터 리몬 1마리(플라스틱·종이·금속 중 선택) | 첫날 |
| 2 | 탐사 1칸 | 2~3일 |
| 3 (새싹) | 일일 미션 | 약 4일 |
| 5 | **동 레이드** | 약 1.5주 |
| 7 (나무) | 재료 교환, 가방 10칸 | 약 3주 |
| 8 | **괴물 보내기** | 약 3.5주 |
| 10 | 탐사 2칸, 가방 15칸 | 약 5주 |
| 15 (숲) | 정원 꾸미기 아이템 (P2) | 약 11주 |

경험치는 v1 그대로다(인증 30/15/15, 배출일 +10, 스캔 +5 × 5회, 주간 목표 +50). 여기에 레이드 참여 하루 +5, 일일 미션 +10이 더해진다.
기능을 한꺼번에 보여 주지 않고 나눠서 열어 **처음 사용자가 압도되지 않게** 한다.

## 6. 도감 3종과 업적

| 도감 | 칸 | 채우는 법 | 완성 보상 |
|---|---|---|---|
| **리몬 도감** | 37 (+반짝이) | 캡슐, 진화 | 타입별 완성 → 그 타입 재료 50 / 일반·희귀 10종 → 전설 퀘스트 |
| **품목 도감** | 40 (`item_guides`) | AI 스캔으로 처음 확인 | 분류별 완성 → 가방 +1칸 / 전체 → 칭호 "분리배출 박사" |
| **수거장 스탬프** | 전주 수거장 전체 | 그 수거장에서 처음 인증 | 우리 동 스탬프 50% → 칭호 "○○동 지킴이". 그 수거장의 **첫 인증자** → "개척자" 표시 |

**업적 예시**: 첫 반짝이 / 7주 연속 주간 목표 / 레이드 피해 1위 / 습관 퀘스트 100회 / 모든 타입 2단계 진화. 업적마다 칭호와 프로필 테두리를 준다.

## 7. 전투와 공략

### 7-1. 전투 규칙 (자동 전투)
- 파티 **3마리**, 자리는 **앞줄 1 / 뒷줄 2**. 적의 단일 공격은 70% 확률로 앞줄을 노린다.
- 매 라운드 **속도 순서**로 행동한다. 스킬은 3라운드마다, 그 외에는 기본 공격(공격력 100%).
- 피해 = 공격력 × 스킬 배율 × 상성(1.5/1/0.75) × 100/(100+방어) × 난수(0.9~1.1)
- 최대 15라운드. 레이드는 **준 피해 총합**을 기록하고, 괴물 보내기 방어전은 승패를 기록한다.
- **작전 설정**(리몬마다): 스킬 사용 시점 = `바로` / `보스 체력 50% 이하` / `아군 체력 30% 이하` 중 선택.
- 서버가 시드 고정 난수로 계산하고 **전투 기록(JSON)** 만 내려준다. 프론트는 카드 흔들림, 숫자 튀기기, 체력바로 재생한다(20초 안팎, 건너뛰기 가능).

### 7-2. 오염 괴물 (레이드 보스) - **실수하기 쉬운 배출 습관이 기믹**

| 보스 | 기믹 | 약점 | 공략 포인트 | 배우는 습관 |
|---|---|---|---|---|
| **음식물 범벅 슬라임** | 매 라운드 아군에 오염 1스택(스택당 공격 −5%) | 플라스틱 | 플라스틱 힐러의 **재생**으로 오염 제거 → 힐러 필수 | 헹궈서 버리기 |
| **라벨 골렘** | 라벨 보호막: 보호막이 있으면 피해 −70% | 유리 | 유리의 치명타가 보호막을 2배로 깸 → **유리 딜러로 보호막부터** | 라벨 떼기 |
| **혼합배출 키메라** | 3라운드마다 약점 타입이 바뀜 | 바뀜 | 한 타입으로 몰면 망함 → **골고루 키운 파티** | 섞지 말고 분리하기 |
| **미세플라스틱 떼** | 작은 적 5마리, 쓰러지지 않은 수만큼 공격 | 비닐·유리 | **광역 공격**(파편 난사)과 휘감기 | 작은 플라스틱도 분리 |
| **스티로폼 거인** | 체력 매우 높음, 3라운드마다 강타 | 종이 | 금속 **도발** + 종이 **보호막**으로 버티기 | 깨끗한 스티로폼만 재활용 |

- 보스는 **매주 월요일 교체**한다(5주 순환). 다음 주 보스를 미리 공개해서 **"다음 주 라벨 골렘 → 유리 리몬 키워 둬야지"** 같은 계획을 세우게 한다.
- 보스 약점 타입은 주마다 바뀐다 → 특정 타입만 키우면 불리해서 **다양한 품목을 제대로 버릴 동기**가 생긴다.

### 7-3. 동 레이드 (협동, 핵심 콘텐츠)
- 각 동에 그 주의 보스가 1마리 나타난다. **동 주민 전체가 체력을 함께 깎는다**(비동기: 각자 편할 때 도전).
- 도전 1회 = 도전권 1장. 하루 무료 1장 + 인증으로 얻은 도전권.
- 보스 체력 = 기준값 × (그 동의 지난 7일 활성 사용자 수) → 사람이 적은 동도 잡을 수 있다(자동 스케일).
- **처치하면** 참여자 전원에게 캡슐 1 + 정화의 결정 1 + 우리 동 청결도 대폭 회복. 기여 상위 3명은 칭호.
- 목표: 보통 참여율인 동이 **3~4일 안에 처치**. 기준값은 전투 엔진 완성 후 시뮬레이션으로 정한다(14장).

### 7-4. 괴물 보내기 (경쟁, 축소판)
- 도전권 1장으로 **다른 동에 작은 오염 괴물을 보낸다.** 괴물 체력 = 내 파티 전투력 × 30, 타입 = 내 선두 리몬 타입.
- 상대 동 주민에게 "○○동에서 괴물이 왔어요" 알림 → **24시간 안에 잡으면** 잡은 사람들이 재료를 나눠 갖고, 보낸 사람은 코인 조금. **못 잡으면** 상대 동 청결도 감소, 보낸 사람은 코인 많이.
- 한 동에 동시에 있을 수 있는 보낸 괴물은 3마리까지. 위기 동(청결도 200 미만)에는 보낼 수 없다.
- 공격받는 쪽에도 득이 있어서(전리품) "당하기만 한다"는 불만이 없다. 강한 파티를 키울 이유도 생긴다.

### 7-5. 탐사 (방치형, 짧은 접속 이유)
- 리몬 1마리를 12시간 보낸다 → 그 타입 재료 2 + 코인 15. 정원 레벨 10에 2칸.
- 탐사 중인 리몬은 레이드에 못 쓴다 → **누구를 보낼지** 작은 선택이 생긴다.
- 재료 비중은 전체의 약 13%로, 실제 배출을 대신하지 못하게 묶어 둔다.

## 8. 지역 청결도 (배경 요소로 축소)

v1의 청결도(0~1000)와 공식(인구 보정 0.5~3.0, 자동 스케일, 자정 −25, 위기 보정)은 그대로 쓴다. 바뀐 점만 적는다.

| 청결도 변화 | v2 |
|---|---|
| 배출 인증 | + R (v1과 같음) |
| 레이드 보스 처치 | **+150** (동 전체 보상, 가장 큰 회복원) |
| 보낸 괴물을 24시간 안에 못 잡음 | − D (v1 공격 공식) |
| 정화 | 삭제 (레이드가 대신함) |
| 시즌 | **1주** (월~일). 보스 교체와 같은 주기 |

- 주간 순위·배지는 유지한다. 다만 홈 화면의 주인공은 **내 리몬과 이번 주 보스**이고, 순위는 레이드 화면 한쪽에 보인다.
- **전주 전체 협동 목표**: "이번 주 전주 인증 N건 달성 → 전원 캡슐 1개". 경쟁과 협동의 균형을 맞춘다.
- v1 시뮬레이션 결론(참여율이 높은 동이 이기고, 인구는 승패와 거의 무관)은 그대로 유효하다. `게임밸런스/simulate.py` 참고.

## 9. 하루 동선 예시

**배출 없는 날 (1~3분)**
1. 앱 열기 → 탐사 보상 수령 → 다른 리몬 다시 보내기 (10초)
2. 저녁에 먹은 음료 캔 스캔 → 배출 방법 확인, 가방에 담김, 습관 퀘스트 +1 (20초)
3. 레이드 1회 도전 → 자동 전투 감상 또는 건너뛰기 (30초)
4. 일일 미션 보상 수령

**배출일 (3~5분)**
1. 수거장 도착 → 인증 촬영 → 판정
2. **가방 정산 연출**: 품목이 하나씩 재료로 바뀜 → 캡슐 등장
3. 캡슐 열기 (희귀? 반짝이?) → 도감 칸 채워짐
4. 재료로 레벨업 → 진화 조건 달성 시 진화 연출
5. 얻은 도전권으로 레이드 2~3회 → 보스 체력 감소, 동 기여 순위 확인

### 12-4. 전투 엔진 의사코드
```python
def simulate(party: list[Unit], enemies: list[Unit], seed: int, max_rounds=15) -> BattleLog:
    rng = Random(seed); log = []
    for rnd in range(1, max_rounds + 1):
        for u in sorted(alive(party + enemies), key=lambda x: -x.spd):
            if u.stunned: u.stunned -= 1; continue
            apply_boss_gimmick(u, rnd, log)                    # 오염 스택, 타입 변경 등
            action = u.skill if ready(u, rnd) and timing_ok(u) else u.basic
            for tgt in pick_targets(action, u, rng):           # 앞줄 70% 규칙
                dmg = u.atk * action.mult * type_mult(u, tgt) * 100 / (100 + tgt.def_) * rng.uniform(0.9, 1.1)
                dmg = tgt.absorb_shield(dmg)
                tgt.hp -= dmg; log.append((rnd, u.id, action.id, tgt.id, round(dmg)))
            if not alive(enemies) or not alive(party): return BattleLog(log, result(...))
    return BattleLog(log, total_damage=...)
```

## 14. 밸런스 검증 계획

| 대상 | 방법 | 시점 |
|---|---|---|
| 지역 청결도 | `게임밸런스/simulate.py` (완료, v1 공식) | 실제 인구 받으면 다시 실행 |
